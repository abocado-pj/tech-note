# Orifolio の本の展開画像

## 2.2.0 の画像

`night-room.png` は承認案 A の夜の壁・植物・照明・青い棚を基準に新規生成した背景。文字・本・UIを含めず、ページの操作部品はHTMLで実装する。

`series-formats.png`、`series-lambda.png`、`series-sql.png` はファイル形式、APIと権限の境界、SQLの集合と表を示すテーマ画像。本型・背表紙・章立ての図案を使わない。

`note-lambda.png`、`note-rails.png`、`note-content.png` は3つの権限、入力の省略と値の違い、読み物の整理を示すノート用画像。

以上7点はこの更新でimagegenにより作成した専用アート。下記の既存表紙と元の記事画像は削除・上書きしない。

## 既存の本の展開画像

ユーザー提供の本棚参照をもとに作成した、文字なしの専用アート。
原本 PNG は 1024×1536。配信用 WebP も同じ寸法・構図を保つ。

| 画像 | 意匠 | 表示上の扱い |
| --- | --- | --- |
| auth-cover-wrap.webp | えんじ、石のアーチ、金色の鍵、植物 | 制作予定の認証本。本文は未制作 |
| database-cover-wrap.webp | セージ、積層した石とガラスの建築、植物 | 公開済み Database Internal の表紙 |

背表紙は x=0〜120、正面は x=120〜1024。両面は同じ画像を使う。
正面の背景幅は 1024/904、背の背景幅は 1024/120。
表示高さをそろえ、背の幅を正面幅×120/904 にすると絵が連続する。

書名は HTML で重ね、本の外にも読みやすいタイトルと公開状態を置く。
本棚の生成画像をページ全体として表示する方式にはしていない。
参照に基づく新規アートであり、元画像の細部の完全複製ではない。
