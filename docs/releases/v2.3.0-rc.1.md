# Orifolio 2.3.0-rc.1

2026-10-15。承認された新聞・シリーズ世界の操作できる実装候補。

**リリース候補です。機能検証は通過しましたが、参照画像への忠実度は独立QAで不合格のため、本番公開していません。**

## 変更

- `/articles/` と既存 `/article-pages/N/` を新聞の紙面に変更。既存本文・元サムネイルを使用し、4記事/頁、検索、分野、前後、左右キー、角ドラッグを実装。
- `/series/world-file-extensions/` に拡張子の作業机を追加。JPEG/PNG/SVG/JSON/YAML/XLSX/CSV/ZIPを選択し、実記事へ進める。未執筆4形式は準備中。
- `/worlds/aws/` に6分野29機構のキャビネット、役割検索、詳細を追加。Lambda/IAMは既存記事、S3/API Gatewayは関連する既存記事と明示。SQS本文は準備中。
- `/worlds/oss/` に分解工房、`/worlds/network/` に5機構と選択つまみ、`/worlds/git/` に映写面・フィルム送り、`/worlds/database/` に4つの地下施設を追加。
- シリーズ一覧から6展示へ到達できる。既存3シリーズと収録順を保持。
- 対象記事の見出し、図の枠、コード、注記、目次、前後記事へ素材に応じた紙面を適用。
- スマホで道具を組み替え、詳細を上部に表示。キーボード・タッチ・reduced-motionに対応。

## 検証と残差

型検査・lint・34テストが成功。静的exportとVercel形式の両buildは349ページを生成した。独立ブラウザQAでは4幅×10画面が全HTTP200、横あふれと実行時エラーなし。新聞の検索・分野・リセット・前後・左右キー・角ドラッグ、全29機構、実記事への導線、目次、reduced-motionを確認した。詳細パネルの遮蔽2件は修正し、DB全4機構を4幅で再確認した。

初回の吹き出し混入、目次の白文字、AWS30個という数の誤り、机の詳細が道具を覆う問題は修正した。

原本の一続きの写真世界に対し、抽出素材とCSSで再構成した机・工房・交換盤・地下断面には、遠近、切り抜き、周辺小物、照明、余白の残差がある。本文は既存記事の内容と長さを維持するため、架空の短い記事サンプルと同じ行組みにはならない。見た目の最終合格をテスト成功だけで判断しない。独立QAの結果と画像比較は作業場所の `evidence/` に保存した。視覚の残差は解消していないため忠実再現の全体合格にはしていない。
