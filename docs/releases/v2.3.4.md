# Orifolio 2.3.4

2026-10-24 JST。ホームの関連メディア紹介を、それぞれのロゴと世界観で表現する。

## 変更と素材

- 基準は公開版2.3.3 / `4aa6aba58817796f16382ea80fe4d4ccbf2df0cc`。元のcheckoutを保持したまま、`design/media-branding-2.3.4`で紹介欄だけを改善する。
- OSS解剖学は承認配置案の重なるソースページをSVGで再構成し、既存の青い分解機械・真鍮・方眼を使用。公開API、内部構造、テスト、依存関係という入口の世界を示す。リンクはOrifolio内の既存`/worlds/oss/`。
- YOMISAKIは現在の公開マストヘッドと同じ朝日と本のロゴ、同じ承認画像の写真部分を使用。紙色・濃紺・朱色の罫線を紹介にもつなぐ。新しいロゴ案を生成して差し替えない。
- JPEG原本は無改変コピーし、SVGのviewBoxでロゴ・写真の領域だけを表示。文字・見出し・CTA・案内文は実DOMで組む。画像中の見本記事は公開データに追加しない。
- 現在のYOMISAKIは別担当が実記事を公開済みで、実ブラウザと公開APIで確認。古いSAMPLE/準備中の紹介を、出典に基づく独自要約・解説の案内へ更新する。記事の自動収集・自動公開を稼働済みと扱わない。
- CSSを紹介欄のModuleへ限定し、既存の重複したグローバル規則を除去。記事、本文、URL、Orifolioロゴ、リッチな3冊と開く動作は保持。依存・認証・料金・サービス設定の変更なし。

## 検証

lint・TypeScript・既存テスト・本番ビルドに加え、PC/スマホ/境界幅、ダーク、キーボード、画像の原本一致、実リンク先を確認する。独立QAは原本と実ブラウザから判断し、固定ビルドのmanifestと保全対象も照合する。証拠はローカル作業領域`evidence/media-branding-20261024/`へ記録。

実機・全文のアクセシビリティ監査・本人の最終デザイン受容は別の確認範囲。OSSロゴのSVGは元の独立ベクター素材を発見したものではなく、承認画像の形をコードとして再構成したもの。世界の機械や写真は装飾的イメージ。
