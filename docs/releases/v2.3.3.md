## 検証と公開手順

1. lint、TypeScript、既存40テストとNext.jsの346経路ビルドを確認する。
2. 1024幅で参照と比較し、1440幅と390幅、320/681/768/900幅の境界も実ブラウザで確認する。書架・目次・3冊の本文・ページ送り・検索・記事・ノート・メディアの実導線を確認する。
3. 固定したexportで最終確認後、リリースcommitのSHAを確定し、公開に必要な同ブランチだけをpushする。mainはGitHub Pagesの別公開を起動するため今回は更新しない。
4. 既存Vercel project `tech-note`、team `appar377s-projects`へ、検証した同一SHAを指定してproduction deploymentを作る。既存のGit接続と認証を使用し、環境変数・権限・課金設定は変更しない。
5. alias `tech-note-opal.vercel.app`、deploymentのREADY、Git SHA、公開後の実ブラウザ・画像hash・主要導線を照合する。公開結果はローカル証拠ディレクトリ`evidence/home-layout-20261023/`へ記録する。

実機Safari/Firefox、音声読み上げ、本人の最終的な見た目の受容は別途確認対象。画像中の機構は装丁の比喩であり技術の構成図を置き換えない。
