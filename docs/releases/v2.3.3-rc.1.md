## 変更

- Database Internalは青緑の記録・索引装置、Lambdaは紺の入口・実行室・鍵・書類棚、Rails Raw SQLは生成りの行選択・一括処理装置を新規制作。元PNGは作業証跡に保持し、WebPを実装に使用する。
- 実際の題名はHTMLで組み、布の色、背表紙、紙口、箔の細線をCSSで重ねる。一覧・本棚・本の冒頭は同じ装丁を共有する。
- 本一覧は公開済み3冊の大きな装丁を先に表示。未公開の企画は件数に含めず、従来の準備中表示を維持する。
- 読み込まれた表紙を持ち上げ、左の綴じ側を軸に厚い表紙と複数の紙が開いて、実際の本文URLへ進む。本文のページ読書では、表示中の紙を複製してめくる。複製は操作・読み上げ・IDから除外し、完了または取消時に除去する。
- 動きを減らす設定、画像未読込、Web Animations API未対応時は通常のリンク移動を使う。修飾キー付きクリックや新しいタブもNext Linkの動作を維持する。開く途中はEscで取消可能。本文の読込開始後は取消案内を終了する。

## 戻し方

本番は未変更。元のcheckout `source` と基準ブランチ `design/lambda-polish-2.3.2-rc.2` はそのまま使用できる。

1. 変更を保存し、作業ツリーがcleanなことを確認する。
2. 基準を確認する場合は `source` のプレビューを使用する。今回の候補は別worktreeのため、元のファイルを戻す操作は不要。
3. 候補を再現する場合はこのブランチで `npm run build`。静的出力を `/tech-note/` に配置して確認する。
4. 将来この変更を採用した後に戻す場合は、候補commitを `git revert` して再検証する。resetやforce-pushは使わない。

固定プレビューはexportのコピーを配信するため、Gitの切替だけでは内容が変わらない。
