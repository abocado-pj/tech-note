## 参照の扱い

参照は1586×992のPC・スマホ合成モック。CSS viewport の実測値ではない。
外側の案名・余白を除き、PC側の1170×910とスマホ側の330×910を比較用のcanvasとした。
この切出しは画像からの測定、同サイズのCSS viewportの採用は推定である。

比較はこのMacのChrome、DPR 1、ズーム100%、日本語、ライト表示、先頭位置、フォント・画像読込後で行う。
390×844、768×1024、狭い幅・ブレークポイント前後も操作・はみ出しを確認する。

原稿の正しいタイトル・説明・見出しを使うため、モックと行数・高さは一致しない。
画像生成された文字や架空の日時は原稿へ転記しない。
本棚の冊数、ノートへの画像追加、シリーズの図案は本人の最新指示と実在する内容を優先した差分。
背景と画像は専用に作成した新規アートであり、モックの画素の完全な複製ではない。
