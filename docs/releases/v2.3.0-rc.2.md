# Orifolio 2.3.0-rc.2

2026-10-15。新聞、6つのシリーズ世界、記事本文を承認画像の構図から再構成した第2候補。

初回のカード分断と原画像UIの切れ端を撤去した。専用環境・透過の物体・実際のHTMLを組み合わせ、選択から既存記事まで操作できる。最終QAと公開判定の記録はこの候補に追記する。

## 変更

- 机: 暖かい窓光、木の天板、緑のマットを連続させ、7個別素材とJSON/YAMLのHTML端末で8形式を選ぶ。
- OSS: 分解された5機構を工房の図面上へ配置。名称の札と選択した機構の説明・実記事リンクをHTML化。
- AWS: 黒と真鍮の6列のキャビネットに29サービス。検索、選択、準備中、関連記事の関係を表示。Aurora/CloudTrail/Athenaはそれぞれ別素材。
- 交換局: 連続した木製筐体・配線の前に5機器。HTTPは巻紙上の実記事導線、DNSは盤に沿う名称、つまみはrangeのキーボード操作。
- Git: 映写機・巻取機・木の編集台を一続きにし、実DOM/SVGの曲線フィルムでcommit/branch/rebase/mergeを選ぶ。
- DB: 洞窟と橋を連続させ、円形書庫、索引の枝、トランザクションの扉、縦のクエリ塔から既存記事を開く。
- 本文: 各世界の見出し、機構のhero、左目次、中央本文、右の読むポイント・次記事、図面、コードと注記へ世界観を継続。本文とコードは既存MDXをそのまま描画。
- 新聞: 主記事・右の小記事・下の2欄。従来の4記事/ページとURLを保ち、5枠目は「次の紙面から」の実記事を紹介。ドラッグ中に次の実紙面を露出させ、曲がった紙の裏面をSVGで描画。下の紙面はinert/aria-hidden。短いドラッグ・取消・二重送りを処理し、矢印・左右キー・タッチも使用可能。
- 900px以下の展示は部品を再配置し、文字を縮めすぎない。reduced-motion時は移動アニメーションと目次の滑らかなスクロールを抑える。

## 素材と内容

承認画像10点のLibrary IDは[初回の参照一覧](v2.3.0-rc.1.md#参照と内容)に保持した。全点を実際に取得して目視した。

専用の生成素材22点は文字・リンクを含まない環境または物体。生成指示、参照、配信ファイルのSHA256は[素材記録](../design/world-assets-v2.json)に保存した。全画面スクリーンショットに透明ボタンを重ねる構造は使用していない。配信用WebPは合計6,512,060 bytes。生成PNGの50,428,211 bytesから約87%削減し、寸法と透過を維持した。

承認画像は構想画でCSS viewportの実測値ではない。PCは1536×1024/DPR1/Chrome/lightで実画面を比較し、参照のないモバイルは330/390/768幅で再配置を確認する。既存記事の実際の題名と長さへ適応するため、架空の短いサンプル本文と同じ改行・高さにはしない。

画像内の架空パーサーやSQS記事・コードを原稿として公開していない。未執筆のJPEG/PNG/XLSX/ZIPやSQS等は準備中。関連する別テーマの記事はその関係を明示する。機械は学習用の比喩で、実際の構成図ではない。

部屋の参照02は机の光・素材の確認に使用し、今回の詳細入口は承認された机03に統合した。別の探索入口は増やしていない。
